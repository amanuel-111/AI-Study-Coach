# 🎓 AI Study Coach

A modern, full-stack AI-powered study coach application designed specifically for Computer Science, Software Engineering, Information Technology, Information Systems, and Cybersecurity students.

## ✨ Features

### 🤖 **AI-Powered Chat Interface**
- **DeepSeek-style modern chat UI** with typing animations
- **Multi-provider AI support** (OpenAI, Google Gemini, Hugging Face, Ollama)
- **Context-aware responses** tailored to your field of study and level
- **Real-time typing effects** for natural conversation flow
- **Chat history management** with session persistence

### 💻 **Coding Practice Platform**
- **Interactive coding problems** with multiple difficulty levels
- **Multi-language support** (Python, Java, JavaScript, C++)
- **AI-powered code analysis** and feedback
- **Submission tracking** and progress monitoring
- **Code templates** for quick start

### 📚 **Comprehensive Learning Tools**
- **Personalized study plans** generated by AI
- **Interactive quizzes** with instant feedback
- **Progress tracking** across different subjects
- **Admin dashboard** for content management

### 🔐 **Secure Authentication**
- **JWT-based authentication** system
- **Role-based access control** (Student/Admin)
- **User profile management**
- **Secure password handling**

## 🛠️ Tech Stack

- **Comprehensive schema** for all features

## 🚀 Quick Start

### **Prerequisites**
- Node.js 18+ and npm
- MAMP (for MySQL database)
- Git

### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/amanuel-111/AI-Study-Coach.git
   cd AI-Study-Coach
   ```

2. **Setup Backend**
   ```bash
   cd backend
   npm install
   
   # Copy environment file
   cp .env.example .env
   
   # Update .env with your settings:
   # - DATABASE_URL for MySQL connection
   # - JWT_SECRET for authentication
   # - GEMINI_API_KEY for AI features (optional)
   ```

3. **Setup Database**
   ```bash
   # Start MAMP and create database 'ai_study_coach'
   
   # Run migrations
   npx prisma migrate dev --name init
   
   # Seed database with sample data
   npx ts-node src/scripts/seed.ts
   ```

4. **Setup Frontend**
   ```bash
   cd ../frontend
   npm install
   ```

5. **Start Development Servers**
   ```bash
   # Terminal 1: Backend (port 3005)
   cd backend && npm run dev
   
   # Terminal 2: Frontend (port 3000)
   cd frontend && npm start
   ```

6. **Access the Application**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:3005

# 🎓 AI Study Coach

AI Study Coach is a full-stack, AI-assisted learning platform designed to help students study, practice programming, take quizzes, create personalized study plans, and track learning progress.

## ✨ Features

### AI Study Assistant
- **Modern chat UI** with typing animations.
- **Multi-provider AI support** (OpenAI, Google Gemini, Hugging Face, Ollama).
- **Context-aware responses** tailored to your field of study and level.
- **Chat history management** with session persistence.
- **Fallback responses** when AI providers are unavailable.

### Coding Practice
- **Interactive coding problems** with multiple difficulty levels.
- **Multi-language support** (Python, Java, JavaScript, C++, C, C#).
- **AI-assisted code analysis** and feedback.
- **Submission tracking** to monitor progress.

### Study Plans
- **Personalized study plans** generated by AI (requires OpenAI API key).

### Quizzes
- **Interactive quizzes** with instant feedback (AI-generated or fallback).

### Progress Tracking
- **Progress tracking** across different subjects.

### Authentication & Roles
- **JWT authentication** system.
- **User profile management**.
- **Secure password hashing**.

## 🛠️ Tech Stack

### **Frontend**
- React 18 (TypeScript)
- Tailwind CSS
- React Query (for server-state management and data fetching)
- React Router
- React Markdown & Lucide React

### **Backend**
- Node.js & Express
- Prisma ORM with MySQL
- JWT & bcryptjs
- Joi for validation

### **AI Integration**
- **OpenAI** (via SDK)
- **Google Gemini** (via REST API)
- **Hugging Face** (via REST API)
- **Ollama** (local inference)

## 🏗️ Architecture

- `frontend/`: React single-page application.
- `backend/`: Express REST API serving the frontend and connecting to the database.
- `docs/`: Project documentation.

## 🚀 Getting Started

### **Prerequisites**
- Node.js 18+
- MySQL database (e.g., local server or MAMP)
- Git

### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/amanuel-111/AI-Study-Coach.git
   cd AI-Study-Coach
   ```

2. **Setup Backend**
   ```bash
   cd backend
   npm install
   
   # Copy environment file
   cp .env.example .env
   ```

3. **Setup Database**
   ```bash
   # Ensure your MySQL server is running and create the database named 'ai_study_coach'
   
   # Run Prisma migrations
   npx prisma migrate dev --name init
   
   # Seed database with sample data
   npm run db:seed
   ```

4. **Setup Frontend**
   ```bash
   cd ../frontend
   npm install
   ```

5. **Start Development Servers**
   ```bash
   # Terminal 1: Backend (runs on port 3001)
   cd backend && npm run dev
   
   # Terminal 2: Frontend (runs on port 3000)
   cd frontend && npm start
   ```

6. **Access the Application**
   - Frontend: `http://localhost:3000`
   - Backend API: `http://localhost:3001`

## 🔐 Environment Variables

### Backend (`backend/.env`)
```env
DATABASE_URL="mysql://root:root@localhost:3306/ai_study_coach"
JWT_SECRET="your-super-secret-jwt-key-here"
JWT_EXPIRES_IN="7d"

# AI Providers (Optional - all have free tiers or run locally)
OPENAI_API_KEY="your-openai-api-key-here"
GEMINI_API_KEY="your-gemini-api-key-here"
HUGGINGFACE_API_KEY="your-huggingface-api-key-here"

PORT=3001
NODE_ENV="development"
FRONTEND_URL="http://localhost:3000"
```

## ⚠️ Current Limitations
- AI features require configured provider credentials in the backend `.env` file to be fully functional.
- Local Ollama support requires Ollama to be installed and running separately.
- Advanced AI features like generating custom study plans and quizzes currently rely on the OpenAI API.
- The coding platform provides AI-assisted analysis but does not compile or execute code on the server.
- The project is intended primarily as a development/demo portfolio application.
